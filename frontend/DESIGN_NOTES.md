# KnowledgeOS interface

The product is an enterprise research workspace with an editorial, quiet visual language: a graphite navigation rail, an ivory working canvas, white panels, and restrained indigo accents. Inter is packaged locally using Fontsource. Fine borders, deliberate spacing, a custom mark, and concise labels establish hierarchy without decorative noise.

Overview connects real corpus and query metrics with an actionable research prompt. Research prioritizes readable, persisted conversations and inspectable evidence. Knowledge Base supports ingestion and the document lifecycle. Intelligence presents measured usage, Architecture explains the implemented pipeline, and Settings exposes sanitized runtime configuration with locally persisted retrieval preferences.

Every page explicitly labels this synthetic portfolio reconstruction. Provider state is reported honestly; retrieval-only responses are labeled as excerpts. No fabricated metrics, simulated streams, or invented activities appear. Loading, empty, unavailable, and mutation states remain distinct. All page data comes through the API. Responsive navigation, visible keyboard focus, accessible Radix dialogs, light/dark themes, and reduced-motion support apply throughout.
